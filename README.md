# Machine Learning and Deep Learning Projects

A collection of notebooks and experiments exploring core machine learning and deep learning methods. The projects use public and sample datasets for practice and demonstrations.

## Topics

- **Supervised learning:** decision trees, K-nearest neighbors, Naive Bayes, random forests, support vector machines, and XGBoost for classification and regression.
- **Unsupervised learning:** K-means clustering and Principal Component Analysis (PCA).
- **Neural networks:** perceptrons, artificial neural networks, CNNs, and CNN-LSTM activity recognition.
- **Computer vision:** MNIST classification with a custom CNN and pretrained ResNet18 using PyTorch.
- **Text modeling:** text classification with attention.
- **Optimization:** gradient methods and training experiments.

## Repository contents

Each project is provided in its own folder or notebook. Dataset choices, required packages, and execution steps can vary; check the individual notebook before running it. Some datasets may need to be downloaded separately.

## Tools

Python · Jupyter Notebook · scikit-learn · PyTorch · XGBoost
